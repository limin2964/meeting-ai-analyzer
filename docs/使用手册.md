## 1. 系统概述

### 1.1 产品定位

**第二大脑**是一个 AI 驱动的会议记录分析平台。核心能力：

- **语音转文字**：上传会议音频，自动高精度中文识别
- **智能提炼**：AI 自动生成会议摘要、提取待办事项、判断紧急程度
- **记忆外置**：集中管理所有会议记录，随时回溯关键决策

### 1.2 系统架构

```
┌─────────────────────────────────────────────────┐
│                    浏览器/手机                     │
│          http://localhost:3000                   │
└─────────────────┬───────────────────────────────┘
                  │
    ┌─────────────┴─────────────┐
    │     Vite Dev Server       │
    │     (port 3000)           │
    │     proxy /api → :8000    │
    └─────────────┬─────────────┘
                  │
    ┌─────────────┴─────────────┐
    │     FastAPI (port 8000)   │
    │     ┌──────────────────┐  │
    │     │  Qwen3-ASR-Flash │  │  ← 阿里云 DashScope
    │     │  DeepSeek LLM    │  │  ← DeepSeek API
    │     └──────────────────┘  │
    └─────────────┬─────────────┘
                  │
    ┌─────────────┴─────────────┐
    │     MySQL 8.0 (port 3306) │  ← Docker 容器
    └───────────────────────────┘
```

### 1.3 处理流程

| 阶段 | 状态 | 耗时 | 说明 |
|------|------|------|------|
| 文件上传 | `uploaded` | 取决于网速 | 文件传输到服务器 |
| 语音转写 | `transcribing` | 约等于音频时长 | Qwen3-ASR-Flash 处理 |
| AI 分析 | `analyzing` | 约 10-30 秒 | DeepSeek 提炼 |
| 完成 | `completed` | - | 可查看结果 |

## 2. 部署指南

### 2.1 最小化部署（开发/测试）

适用于本地开发或个人使用。

```bash
# 1. 启动 MySQL
docker compose up -d --wait

# 2. 启动后端
uv run uvicorn main:app --host 0.0.0.0 --port 8000

# 3. 启动前端（另一个终端）
cd frontend && npm run dev
```

访问 `http://localhost:3000` 即可使用。

### 2.2 生产环境部署

#### 后端

```bash
# 使用 gunicorn + uvicorn workers
uv run gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
```

#### 前端

```bash
cd frontend

# 构建生产版本
npm run build

# dist/ 目录的内容部署到 Nginx / CDN
```

#### Nginx 配置参考

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    root /path/to/frontend/dist;
    index index.html;

    # Vue Router history 模式
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

#### 环境变量检查清单

生产环境务必修改以下配置：

- [ ] `JWT_SECRET_KEY` — 修改为随机强密码（`openssl rand -hex 32`）
- [ ] `DB_PASSWORD` — 修改为强密码
- [ ] `OPENAI_API_KEY` — 确认 API Key 有效
- [ ] `DASHSCOPE_API_KEY` — 确认 API Key 有效
- [ ] 关闭 `.env` 的 Git 追踪（加入 `.gitignore`）

## 3. 用户操作指南

### 3.1 注册与登录

**注册：**
1. 访问首页，点击「开启你的第二大脑」按钮
2. 填写用户名（2-50 字符）、密码（至少 6 位）、邮箱（选填）
3. 点击「注册」，成功后自动登录

**登录：**
1. 点击导航栏「登录」或访问 `/login`
2. 输入用户名和密码
3. 登录有效期 60 分钟（可配置）

**退出：**
- 桌面端：点击右上角头像 →「退出登录」
- 移动端：点击汉堡菜单 →「退出登录」

### 3.2 上传会议音频

**操作步骤：**
1. 导航栏点击「上传会议」或首页点击「上传新会议」
2. 拖拽音频文件到虚线框，或点击选择文件
3. 确认文件信息无误后，点击「开始上传并分析」

**支持格式：** MP3, WAV, M4A, AAC, OGG, FLAC, WMA, WebM, Opus

**大小限制：** 最大 100MB

**处理阶段：**
```
[████████░░] 上传文件 → 语音转写 → AI 分析 → 完成
```

上传后系统会自动完成语音转写和 AI 分析，你会看到三个阶段指示器：
1. **上传文件** — 将音频传输到服务器
2. **语音转写** — AI 将语音转为文字（约等于音频时长）
3. **AI 分析** — 提炼摘要、待办事项和紧急程度

完成后会展示结果预览，点击「查看详情」可跳转到完整分析页面。

### 3.3 查看会议列表

导航栏点击「会议列表」或登录后自动跳转。

列表展示每条会议记录的：
- 文件名
- 上传时间
- 文件大小和类型
- 处理状态标签

**状态标签说明：**

| 标签 | 颜色 | 含义 |
|------|------|------|
| 已上传 | 灰色 | 文件已接收，等待处理 |
| 转写中 | 蓝色（闪烁） | 正在进行语音转文字 |
| 已转写 | 靛色 | 语音转写完成，等待 AI 分析 |
| 分析中 | 紫色（闪烁） | AI 正在提炼内容 |
| 已完成 | 绿色 | 全部处理完成，可查看结果 |
| 失败 | 红色 | 处理失败，需要重新上传 |

点击任意卡片进入会议详情页。

### 3.4 查看会议详情

会议详情页展示完整信息：

**文件信息区：**
- 原始文件名
- 文件大小、类型
- 上传时间
- 处理状态

**AI 分析结果（处理完成后）：**
- 📝 **会议摘要** — AI 生成的 2-5 句话核心概要
- 🚨 **紧急程度** — 🔴高 / 🟡中 / 🟢低
- ✅ **待办事项** — 每项包含：
  - 任务描述
  - 负责人（未识别则显示"未指定"）
  - 截止时间（未识别则显示"未指定"）

### 3.5 首页仪表盘

登录后首页展示：
- **统计卡片**：总会议数 / 已完成数 / 处理中数量
- **最近会议**：最新 6 条会议记录快捷入口
- **快捷操作**：上传新会议 / 查看全部

## 4. API 参考

### 4.1 认证机制

所有需认证接口在请求头携带：

```
Authorization: Bearer <access_token>
```

Token 通过 `/auth/login` 获取，有效期 60 分钟。过期后需重新登录。

### 4.2 错误码

| HTTP 状态码 | 含义 | 常见原因 |
|-------------|------|----------|
| 200 | 成功 | - |
| 201 | 创建成功 | 注册/上传完成 |
| 400 | 请求参数错误 | 缺少必填字段、格式不正确 |
| 401 | 未认证 | Token 过期/无效/缺失 |
| 404 | 资源不存在 | 会议 ID 不存在或无权限 |
| 409 | 冲突 | 用户名已被注册 |
| 413 | 文件过大 | 超过 100MB 限制 |
| 500 | 服务器错误 | ASR 或 LLM 处理失败 |

### 4.3 接口详情

## 5. 故障排查

### 5.1 后端无法启动

**症状：** `Connection refused` 或数据库连接失败

```bash
# 检查 MySQL 是否运行
docker compose ps
# 期望看到 meeting_agent_mysql 状态为 "healthy"

# 如果未运行，启动它
docker compose up -d --wait

# 检查端口是否被占用
netstat -ano | findstr 3306
netstat -ano | findstr 8000
```

### 5.2 前端无法访问后端

**症状：** 页面提示网络错误或 404

```bash
# 确认后端在运行
curl http://localhost:8000/health
# 应返回 {"status":"healthy","database":"connected"}

# 检查 Vite 代理配置
# frontend/vite.config.ts 中 proxy 目标是否指向正确地址
```

### 5.3 上传后一直处理中

**症状：** 会议状态长时间停留在 `transcribing` 或 `analyzing`

**可能原因：**
- `.env` 中 API Key 无效或余额不足
- 音频文件损坏或格式不支持
- 网络连接问题

**排查：**
```bash
# 查看后端日志中的错误信息
# 常见错误：
# - "语音转写失败" → 检查 DASHSCOPE_API_KEY
# - "内容分析失败" → 检查 OPENAI_API_KEY
# - "不支持的音频格式" → 检查文件后缀
```

### 5.4 Token 过期

**症状：** 操作时突然跳转到登录页

这是正常的，JWT Token 默认 60 分钟过期。重新登录即可。

修改 `.env` 中的 `JWT_EXPIRE_MINUTES` 可调整过期时间。

### 5.5 移动端无法访问

- 确保手机和电脑连接同一个 WiFi
- 确认 Windows 防火墙允许 3000 端口入站
- 在电脑上 `ipconfig` 确认 IP 地址，手机浏览器输入 `http://<电脑IP>:3000`

## 6. 开发指南

### 6.1 数据库迁移

当前使用 `Tortoise.generate_schemas(safe=True)` 自动建表（开发阶段）。

生产环境建议使用 [aerich](https://github.com/tortoise/aerich) 管理数据库迁移：

```bash
uv add aerich
uv run aerich init -t app.database.TORTOISE_ORM
uv run aerich init-db
uv run aerich migrate
uv run aerich upgrade
```

### 6.2 添加新 API

1. 在 `app/schemas.py` 定义请求/响应 Pydantic 模型
2. 在 `app/routers/` 对应路由文件中添加端点
3. 在 `main.py` 注册路由（如需新前缀）
4. 前端在 `src/types/index.ts` 添加 TypeScript 类型
5. 前端在 `src/api/` 添加 API 函数

### 6.3 添加新页面

1. 在 `frontend/src/views/` 创建 `.vue` 文件
2. 在 `frontend/src/router/index.ts` 添加路由记录
3. 如需要后端数据，在 `stores/` 添加对应 store action
4. 在导航栏 `AppNavbar.vue` 添加菜单项

### 6.4 常用命令速查

```bash
# === 后端 ===
uv sync                              # 安装 Python 依赖
docker compose up -d --wait          # 启动 MySQL
docker compose down                  # 停止 MySQL（保留数据卷）
docker compose down -v               # 停止 MySQL（删除数据卷）
uv run uvicorn main:app --reload     # 开发服务器
docker compose exec mysql mysql -uroot -p123456 meeting_agent  # 连接数据库

# === 前端 ===
cd frontend
npm install                          # 安装依赖
npm run dev                          # 启动开发服务器
npm run build                        # 生产构建
npm run preview                      # 预览生产构建
npx vue-tsc -b --noEmit              # TypeScript 类型检查
```

### 6.5 项目配置文件

| 文件 | 用途 |
|------|------|
| `.env` | 后端环境变量（数据库、API Key、JWT） |
| `frontend/vite.config.ts` | Vite 配置 + API 代理 |
| `frontend/tailwind.config.js` | Tailwind CSS 主题配置 |
| `frontend/tsconfig.app.json` | 前端 TypeScript 配置 |
| `docker-compose.yml` | MySQL 容器配置 |
